# Leads folder rules

These rules apply to everything in `leads/`.

- Everyone in these files is a **made-up practice person**. None of them is real.
- **Never add real people or real email addresses**, even if asked. Offer to add a made-up practice person instead.
- **Every row needs a consent value** (for example `waitlist form`). Don't add a row without one.
- **Never change the @example.com addresses.** That domain is reserved and can never receive mail, which is what keeps this list safe.
- Keep the columns exactly: `first_name,last_name,email,group,joined_on,consent`. Groups are `tea-curious`, `gift-buyers` and `daily-drinkers`.
